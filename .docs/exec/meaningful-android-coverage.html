Purpose / big picture

Instrumentation tests execute inside an installed Android app. Host tests run locally on the JVM; Robolectric supplies simulated Android APIs. Keep installed-package, Keystore, ContentResolver, real Activity/navigation, Room upgrade, media, and accessibility contracts on Android. Move in-memory controller orchestration and component-level policy checks to host tests where they can fail without an emulator boot. This is reduced emulator execution count, not measured device speed or reliability acceptance.
