Purpose / Big Picture

Keep compilation, testing, CI, and app runtime dependencies maintained without buying unnecessary migrations. New installs require Android 16 (API 36); Android 17 (API 37) remains the compilation and target platform. API is Android's numeric platform level. UI navigation, media autoplay, recovery, and persisted user data must retain their existing behavior.

Context and orientation

gradle/libs.versions.toml owns library/plugin versions. The Gradle wrapper selects the build engine. AGP (Android Gradle Plugin) builds Android packages; Kotlin includes the Compose compiler; Detekt analyzes Kotlin; Kover measures host-test coverage. Android modules are app, core-data-android, baseline-profile, and macrobenchmark. The remaining modules use JVM tests. Robolectric simulates Android for host tests. GitHub workflows separately run emulator tests and release publishing.

The WebP decoder named Legacy also implements controllable animation and static overview frames, so its dependency is not obsolete when older Android versions are dropped. Credential and database migrations remain required for existing data.
