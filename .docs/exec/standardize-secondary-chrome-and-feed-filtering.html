Purpose / Big Picture

Codex detail, Creator Profile, and Viewer use the same compact frame: Back on the left, title/context in the center, and route actions on the right. Search, For You, and Creator keep their filter values and options but present them in one dismissible sheet structure. The existing filter FAB changes color when a non-default filter is active; no summary row is added above the grid.

Context And Orientation

The shared layer owns geometry and presentation only. Route owners retain filter data because their option sets and refresh consequences differ.

Phases And Work Plan

  3. Wrap each route's existing controls in the shared transient sheet.
  4. Compute active state from route-owned non-default values.
