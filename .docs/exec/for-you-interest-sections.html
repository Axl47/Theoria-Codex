For You interest sections

Owner: Codex. Created 2026-11-01. Status: complete. Implementation and host validation complete; physical-device and live-provider acceptance remain unperformed. Next: optional isolated-device review under the project safety rules. Local code and host checks only.

For You opens a Saved-style overview with a mixed feed, distinct interest previews, and an adjacent discovery section. Each interest opens the existing full feed with its exact source-native tags. Pinning uses Saved Searches; dismissing uses the existing profile blacklist.

Purpose · Context · Phases · Work · Validation · Living log · Recovery

Purpose / Big picture

Users choose among several visible interests instead of relying on one randomly selected broad tag. Opening a section retains its first page and continuation (the information required to fetch the next page). Returning from Viewer or the section retains the overview. Shuffle replaces unpinned suggestions; saved pins survive restarts.

Context and orientation

app/src/main/java/com/theoriacodex/app/recommend/ForYouCoordinator.kt executes per-source searches. ForYouViewModel.kt and state/ForYouStateContract.kt retain route state and reject stale requests. ForYouScreen.kt renders shared SearchResultCard with existing simultaneous playback. app/src/main/java/com/theoriacodex/app/ui/routes/SavedCodexRoute.kt now reuses the extracted app/src/main/java/com/theoriacodex/app/ui/components/PostShelfSection.kt carousel. app-logic/src/main/kotlin/com/theoriacodex/app/codex/CodexSaveRelevance.kt supplies normalized tag overlap used by the smart save picker. core-domain recommendation/TagAffinity.kt supplies co-occurrence statistics. TagCountCoordinator.kt and TagSuggestionStore.kt supply bounded, cached provider counts. SavedSearchRepository persists source-native FYP searches device-wide; blacklist settings remain profile-specific.

Design: reuse MaterialTheme surface, onSurface, primary, outline and onSurfaceVariant colors and existing typography. Left-aligned section titles, 164dp horizontal post cards, quiet actions with 48dp touch targets. The posts carry the visual identity; no new palette, fonts or decorative panels.

Saved FYP searches already retain exact per-source tags. Robolectric Android 36 requires Java 21+, while the shell defaults to Java 19; use JAVA_HOME=/opt/homebrew/opt/openjdk@25/libexec/openjdk.jdk/Contents/Home for Compose tests.
