Separate fullscreen recommendation navigation

Purpose

Keep the bottom thumbnail strip limited to the original feed. From liked post A, Next still opens original next post B. Opening recommendations R1…Rn creates a temporary browsing branch: swipes traverse recommendations, and Next from Rn also opens B. Previous from R1 returns A. The bottom strip remains anchored to A while a recommendation is displayed.

Context and data flow

Production Viewer paths are relative to app/src/main/java/com/theoriacodex/app/viewer/; ViewerRoute.kt is in app/src/main/java/com/theoriacodex/app/ui/routes/. Viewer tests are under app/src/test/java/com/theoriacodex/app/viewer/.

ViewerSessionCoordinator.kt defines the retained ViewerSession. ViewerViewModel owns immutable backing pages and saved restoration identity. ViewerRoute.kt projects related feed state into ViewerUiState. ViewerScreen.kt drives nested post/gallery pagers using page indices. Currently recommendations append to session.posts, so the bottom strip and swipe order both include them.

Keep one backing collection for media state and resolution, but explicitly record recommendation-only IDs and the branch's original anchor. Derive a displayed page order and a separate original strip order. Dispatch page selections back to backing indices by post identity. Recreate the pager position only when entering/leaving the branch so forward drag direction remains correct at its exit. Preserve gallery navigation and media positions. Source pagination appends original posts without promoting recommendation-only IDs into the strip.

States: original feed, opening a recommendation, browsing its branch, selecting an original thumbnail, chain likes, source pagination, hidden/dismissed shelf, and cold restoration. Closing/dismissing the shelf must not corrupt a currently displayed recommendation's return path. Cold restoration uses the original anchor/order; recommendation branches remain transient.

Discoveries

Pager item keys must use the existing source-qualified string encoding, not PostId objects. Entering/leaving a branch must replace the pager provider together with its remembered state; retaining the old provider could pair the previous page count with the new shorter key list.

A target-index override alone would reverse the slide from the last appended recommendation back to original B. A branch display order keeps B physically after Rn while preserving the original bottom-strip order.

Decisions

Use post IDs to map visible pages to the existing immutable renderer state. Do not duplicate decoders or replace the gallery pager. Recommendation membership is session-local, and cold restore returns to the source anchor.
