Source-Aware Recent Searches

Status: complete, deterministically validated, and user-accepted. Owner: Codex.

Purpose

Make Recent Searches describe the terms and sources that actually ran, including temporary multi-source searches, while preserving old search history and the existing Search persistence boundary.

Runtime flow

  1. Search executes a source, global Unified, or temporary multi-source request.
  2. After an accepted result, Search records the query, execution identity, search kind, and participating source keys in Recents.
  3. Room stores the new metadata in a versioned wrapper inside the existing query payload column. The decoder continues to accept the previous raw Query payload.
  4. Recents renders tags as the title, source context only for Unified and Multi-Search rows, and time beneath the leading search/source icon.
  5. Opening a Multi-Search restores its explicit source set. Opening ordinary Unified or source searches retains their existing behavior.

UI states

  • Source search: shared source logo, time below it, comma-separated terms, no subtitle.
  • Unified search: search icon, time below it, comma-separated terms, and the participating sources.
  • Multi-Search: search icon, time below it, comma-separated terms, and a Multi-Search source summary.
  • Legacy Unified record without source metadata: remains readable and omits an invented source list.
  • Query without terms: uses a stable No tags title.

Error and compatibility boundaries

  • No Room schema migration is introduced.
  • Malformed or unsupported new payloads continue to fail closed through the repository flow.
  • A historical Multi-Search whose explicit sources no longer form a valid multi-source set reports that its sources are unavailable instead of silently becoming Unified.
  • Temporary searches remain excluded from durable applied-query and scroll restoration; only their successful Recents event becomes durable.

Acceptance and validation

  • Repository tests prove new payload round-trip, old payload decoding, exact source metadata, and Undo restoration.
  • Search tests prove temporary searches are recorded and historical Multi-Search restores the explicit scope.
  • Presentation tests prove comma-separated tags, no sort label, source-only rows without subtitles, and Unified/Multi-Search source summaries.
  • Run focused JVM tests, Debug compilation, app/core-data checks relevant to edited owners, HTML validation, and diff checks once.
