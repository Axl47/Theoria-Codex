Purpose

Preserve unrelated Recents history, make everyday storage failures recoverable, remove repeated whole-library UI work, retain healthy Search results through page failures, and simplify shared query/media/transfer ownership. Completed behavior must preserve simultaneous visible autoplay, canonical post identity, exact search replay and durable local data.

Context and orientation

app owns Android routes, UI and platform media. app-logic owns platform-free policies. core-domain owns immutable provider/query models and orchestration. core-data owns repository contracts and typed file storage. core-data-android owns Room tables and transactions. core-sources owns provider transport/parsing. A route generation is the identity used to reject an obsolete asynchronous result; a canonical post ID is provider plus provider post ID. FYP means the For You recommendation feed. Main means Android’s UI dispatcher.

One agent owns all edits. No deployment, release, live database or daily-driver package changes are authorized or needed. Device acceptance uses isolated Debug/acceptance/benchmark packages only after packaged-ID/signature proof. Physical performance results are distinct from host operation counts. Do not weaken frozen file budgets, cancellation, migration or autoplay contracts.
