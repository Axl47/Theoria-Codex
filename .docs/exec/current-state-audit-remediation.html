Context and orientation

app owns Android routes, UI and platform media. app-logic owns platform-free policies. core-domain owns immutable provider/query models and orchestration. core-data owns repository contracts and typed file storage. core-data-android owns Room tables and transactions. core-sources owns provider transport/parsing. Main means Android’s UI dispatcher.

One agent owns all edits. No deployment, release, live database or daily-driver package changes are authorized or needed. Device acceptance uses isolated Debug/acceptance/benchmark packages only after packaged-ID/signature proof. Physical performance results are distinct from host operation counts.
