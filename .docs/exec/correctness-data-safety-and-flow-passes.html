Correctness, data safety and flow passes

Purpose / Big Picture

An audit found three groups of gaps. The app wasted cellular data by prefetching a video file the Viewer then didn't play. The library, which exists only on the phone by design, had no automatic copy off it, and restoring a backup created duplicates. Provider links opened in the browser, and a feed that failed offline stayed failed until tapped. After this work the app fetches the stream it plays, backs up daily to a folder the user picks, restores without duplicates, offers Undo for big deletes, accepts shared links, and retries feeds when the network returns.

Current Status

Implemented and validated on the emulator; in review. Next action: complete review, CI and merge. The cross-provider duplicate idea was dropped at the developer's request because duplicates have not been seen in use.

Surprises And Discoveries

  • The manifest's autoVerify left all 17 sites Disabled on the emulator, confirming links went to the browser.
  • Profile collection fails with UiAutomationService already registered while agent-device holds the emulator. Close its session first.
  • The system folder picker ignores the driver's instant tap; a press held for 150 ms works.
  • Leaving within seconds of a cold start skips that backup check, because the shell's observer isn't registered yet. That session changed nothing, and the next exit runs it.

Outcomes And Retrospective

All three passes shipped together. Performance benefit from the profile and metered streams was not measured on a physical device, so this plan claims no numbers for them. Live provider behaviour with real accounts, including the For You sign-in route with an expired account, is proven by tests only and needs a check on a real account. The lesson worth keeping: when two code paths must agree on a cache key, give them one resolver instead of two copies of the same policy.

Recovery

Each commit is independent and can be reverted alone. Backups written by this version also open on older versions, because the format version is unchanged and unknown fields are ignored. To undo auto backup on a device, use Turn off in Settings; existing files stay in the folder. If profile generation fails, close any device driver session, confirm ANDROID_SERIAL, and rerun; it changes nothing but the two files in app/src/release/generated/baselineProfiles/.
