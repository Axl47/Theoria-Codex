Viewer brightness and volume gestures

Owner: Codex · 2026-10-22 · Status: complete

Swipe vertically on the left half of a fullscreen video to adjust display brightness, or on the right half to adjust system media volume. A centered horizontal indicator shows the current level and changes its icon with the level.

PurposeContextWork planValidationLiving logRecovery

Purpose and current status

Feature implementation and 15 host tests are complete. The user additionally requested repairs for all existing Detekt findings and lint errors reported during this work; these repairs are also complete. User confirmed brightness applies only in Viewer and normal brightness returns on exit. Volume controls Android’s media stream, including mute at zero. Up increases; down decreases. Indicators remain visible throughout a gesture and fade afterward. The scope is video pages outside picture-in-picture (PiP, Android’s floating video window).

Context and orientation

app/src/main/java/com/theoriacodex/app/viewer/ViewerScreen.kt owns the fullscreen route, pagers, and controls. ViewerMediaPage.kt selects renderers and overlays a gesture area with a reserved timeline touch area. Existing horizontal swipes navigate, two-finger gestures transform, and taps toggle controls or seek. Android window brightness changes the actual display without changing saved system brightness; AudioManager controls the system media stream.

The controller will live for the Viewer route so brightness does not reset between pages. Leaving the route or entering PiP restores the previous window brightness. Returning from PiP resumes the Viewer override. Errors and fixed-volume devices show unavailable feedback rather than claiming a change.
