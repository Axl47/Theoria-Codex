Per-Codex statistics

Owner: Codex · 2026-10-16 · Status: Complete

Extend Settings Stats with individual collection time, opens, viewed posts and top-five breakdowns.

Context · Work · Validation · Log

Purpose

Choose a Codex in Settings Stats, initially the most watched collection, and see browsing/watching time, entries, post opens, and videos/images ranked by foreground viewing time.

Context and orientation

core-data StatisticsRepositories.kt stores lifetime counters in statistics_store_v1.json. AppUsageTracker owns foreground timing. TheoriaApp owns Codex routes; ViewerRoute owns current media and retains ViewerLaunchContext with codex:<id> query identity. StatisticsProjection supplies SettingsScreen. New optional fields keep old files readable. No production or device changes.

Phases and work plan

  1. Add durable per-Codex and per-post counters to core-data repository and its in-memory fixture. Test round-trip persistence and attribution.
  2. Extend AppUsageTracker with Codex/media target transitions; flush on target changes and background. Wire Codex detail and selected Viewer media. Record opens via existing one-shot visible-post workflow.
  3. Project profile-visible collections, ordered by watching time. Add selector, empty states, totals and top-five rows in Settings Stats.

Posts seen counts Viewer opens; videos and images rank cumulative selected-media foreground time. GIF/Ugoira count with images. Existing app time categories remain unchanged. Failed persistence remains best effort as existing counters are. Old counters cannot reconstruct historical per-post viewing.

Validation and acceptance

From repository root run focused core-data StatisticsRepositoriesTest, app-logic StatisticsProjectionTest and app AppUsageTrackerTest / SettingsStatisticsSourceTest; compile Debug and run Detekt with parallel disabled. Run offline lint after code generation. Tests must establish no background time, correct route/media attribution, persistence and deterministic top-five selection. Manual acceptance: enter a collection, open image/video, background/resume, leave, then Settings Stats displays totals and collection selector. Do not install on daily-driver channels.
