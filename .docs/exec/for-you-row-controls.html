Purpose

Dismiss removes only its row, preserving every other query, page and position. Save to Codex saves the exact FYP search into Saved Searches and then removes its row. The source dropdown moves to the center of the header, matching Recents; redundant source labels disappear. Reorder uses Codex's drag and accessible move controls. New search appends one distinct generated search. Refresh also re-seeds the first mixed For You row.

Context and orientation

app/src/main/java/com/theoriacodex/app/recommend/ForYouHomeController.kt owns preview lifetimes. ForYouViewModel.kt synchronizes profile settings and currently refreshes after blacklist changes. A row-local blacklist mutation must be recognized before repository emissions so neither the feed nor the overview is refreshed. ForYouSections.kt persists pinned searches and queries generated interests. Existing source-native saved FYP searches remain compatible. Saving then hiding a search preserves durable storage and prevents the saved row from returning as a pin. Existing pin behavior stays available.

app/src/main/java/com/theoriacodex/app/codex/CodexListUiState.kt and CodexReorderControls.kt contain reusable reorder state and gesture/accessibility behavior. Extract those mechanics for reuse rather than duplicating drag logic. Preserve Codex behavior and its tests.

Decisions

Dismiss and Save to Codex reuse existing profile-specific hidden search settings; saved rows are filtered out of pinned FYP entries, preserving saved searches without a new schema. Row mutations adopt their own blacklist emissions without regenerating other feeds. New search means one generated personalized search appended to the overview. Existing Pin continues saving a row while keeping it in FYP. The first For You row remains fixed at the top; custom search rows are reorderable.

Surprises and discoveries

Changing only the dismissal callback would be insufficient: Settings flow can emit before the update call returns. Mutation admission must guard both that emission and the final callback. The reported comparison-contract failure came from sampling random weights inside a sort comparator. Each weight is now sampled once before sorting, with a 300-tag test verifying one draw per tag and deterministic ordering for a fixed seed. This was committed separately as 6ae90fa7.

Outcomes

The overview keeps other rows, exact queries, pages and scroll identities when Dismiss or Save to Codex removes a row. Undo restores the dismissed row at its former position. The shared ReorderListState and ListReorderHandle retain Codex mechanics for both surfaces. New search excludes existing query IDs before fetching one additional page. Refresh re-seeds the first mixed row even after previewing an interest. Hidden pinned searches remain in Saved Searches but are not reintroduced into FYP.
