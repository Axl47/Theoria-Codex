Purpose / Big picture

Opening a post in a large Codex should leave the app's UI thread available while the collection's media references are prepared. A Codex is an ordered saved collection; normalization restores canonical remote references from transient offline playback references.

This fixes a demonstrated source of UI-thread work. It does not establish that this work explains all reported opening/closing lag.

Context and orientation

app/src/main/java/com/theoriacodex/app/ui/TheoriaApp.kt, in openCodexViewer, launches preparation on the route/UI scope before navigating. ViewerRouteWorkflow.preparePostsForLaunch maps every post, calling OfflineMediaCoordinator.withoutOfflineLocations. The store examines and rebuilds media collections even for remote-only galleries. Cost therefore grows with all posts and their gallery media, rather than just visible cards.

The workflow already injects providerDispatcher (default Dispatchers.Default) for background parsing. Use that same dispatcher for the collection map. Selected/current-plus-next offline hydration remains bounded to two posts. Required selected-post resolution stays after preparation on its existing path, including its existing error handling. Existing offline fallbacks remain intact.

Inspection also found eager full-collection page/media state construction in app/src/main/java/com/theoriacodex/app/viewer/state/ViewerStateReducer.kt:createViewerUiState. It remains synchronous and is a separate candidate for future measurement. Grid video players already pool leases, pace preparation/cooling, and defer player release. No evidence justifies reducing visible autoplay or changing those timings.

Surprises and discoveries

The suspected grid stop/preparation path already has pooling, paced preparation/cooling, and delayed release. The concrete collection-size-dependent issue appears earlier: an unsuspended full-collection offline normalization map on the route dispatcher. The first batch confirmed all 2,000 list accesses run outside the route thread. Cancellation at index 10 stops before normalization of that item, after 11 accesses.

Decision log

2026-10-27 / Codex: Reuse the existing injected dispatcher instead of introducing a scheduler, changing autoplay, or speculating about decoder budgets. Keep only the map off-thread so selected-post persistence/callback context stays as before.
