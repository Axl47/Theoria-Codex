FYP Recommendation History in Recents

Status: cold-start historical replay repaired and deterministically validated; manual isolated-Debug acceptance remains. Owner: current Codex task.

Purpose

Add an FYP section to Recents that durably captures recommendation searches, not their result posts, and includes those searches in All.

Runtime flow

  1. For You accepts a root recommendation generation in ForYouCoordinator.
  2. The coordinator records one FYP search with exact tags per source, participating-source order, sort, and seed identity.
  3. The versioned recent-search payload persists the FYP kind and source-specific tags through the existing Room column; no schema migration is needed.
  4. The Recents boundary separates normal Searches from FYP searches while the existing activity merge includes both in All.
  5. Clicking an FYP row dispatches a typed replay to the navigation-owned For You route, then jumps directly to For You. The coordinator rebuilds the original per-source query overrides and sort.

Behavior and error boundaries

  • Only accepted root generations are recorded; pagination and stale, cancelled, or failed provider work never create FYP history.
  • Result posts are not recorded as FYP history. A post opened from For You follows the existing Watched contract.
  • FYP clear has exact Undo without clearing normal Searches. All clear/Undo includes both.
  • A Recents write failure must not discard an otherwise valid recommendation feed; cancellation still propagates.
  • An FYP replay supersedes automatic/current refresh work. If a saved source is unavailable, For You shows the existing refresh error instead of silently changing the search.
  • A fresh For You route owner buffers the replay until both settings/profile/likes and source availability synchronize. This prevents either the zero-likes clear path or the first capability reconciliation from erasing or cancelling the historical request.
  • Once an explicit historical seed exists, an empty provider result reports no recommendations rather than asking the user to train For You.
  • Legacy FYP rows without source-specific metadata remain clickable by applying their saved aggregate tags to each participating source.
  • Search titles show every tag and wrap instead of truncating with an ellipsis.
  • Recents filter order is Watched, Codex, Searches, FYP, All.
