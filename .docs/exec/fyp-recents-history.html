FYP Recommendation History in Recents

Status: implementation and deterministic host validation complete; manual isolated-Debug acceptance remains. Owner: current Codex task.

Purpose

Add an FYP section to Recents that durably captures accepted recommendation results and includes those memberships in All without conflating them with Watched or Codex.

Runtime flow

  1. For You accepts a root recommendation generation or appended page in ForYouCoordinator.
  2. The coordinator records the accepted page as one bounded Recents batch with FOR_YOU origin, the current seed identity, and the independent FYP section.
  3. The existing Room post payload and section-keyed membership table persist and deduplicate canonical posts; no schema migration is needed.
  4. The Recents boundary projects Watched, Codex, and FYP independently. FYP renders through the shared post grid and All receives FYP through the existing activity merge.
  5. Opening an FYP item from either FYP or All creates a static Recents Viewer session scoped to the FYP membership list.

Behavior and error boundaries

  • Only admitted root/page results are recorded; stale, cancelled, and failed provider work never enters Recents.
  • Root generation records its accepted page; pagination records only the accepted appended page.
  • A canonical post can independently belong to Watched, Codex, and FYP.
  • FYP clear has exact Undo. All clear/Undo includes FYP alongside the existing sections and searches.
  • A Recents write failure must not discard an otherwise valid recommendation feed; cancellation still propagates.
  • The existing global Recents bound remains authoritative for post history.
