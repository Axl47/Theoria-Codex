FYP Recommendation History in Recents

Status: corrected implementation and deterministic host validation complete; manual isolated-Debug acceptance remains. Owner: current Codex task.

Purpose

Add an FYP section to Recents that durably captures recommendation searches, not their result posts, and includes those searches in All.

Runtime flow

  1. For You accepts a root recommendation generation in ForYouCoordinator.
  2. The coordinator records one FYP search with the generated seed tags, participating sources, and seed identity.
  3. The versioned recent-search payload persists the FYP kind through the existing Room column; no schema migration is needed.
  4. The Recents boundary separates normal Searches from FYP searches while the existing activity merge includes both in All.
  5. FYP rows are historical generation records rather than replayable Search queries because providers may have received different seed tags.

Behavior and error boundaries

  • Only accepted root generations are recorded; pagination and stale, cancelled, or failed provider work never create FYP history.
  • Result posts are not recorded as FYP history. A post opened from For You follows the existing Watched contract.
  • FYP clear has exact Undo without clearing normal Searches. All clear/Undo includes both.
  • A Recents write failure must not discard an otherwise valid recommendation feed; cancellation still propagates.
  • Search titles show every tag and wrap instead of truncating with an ellipsis.

Acceptance and validation

  • Repository tests prove FYP search identity, Room persistence, activity inclusion, and independent clearing.
  • Coordinator tests prove one accepted root search is recorded and pagination does not add history.
  • Clear workflow tests prove FYP and All snapshots restore exactly.
  • Presentation coverage proves FYP source context and full tag-title construction.
