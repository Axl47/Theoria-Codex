Saved Codex

Group Likes, Followed and Saved Searches under Saved, with horizontal post previews and existing full collection destinations.

Status: Complete · Codex · 2026-10-16

Context · Work · Validation · Living log

Purpose and current status

The Library shows a Saved tile with Likes, Followed and Search counts. Opening it shows three titled, counted carousels. Titles open existing collection screens. The post-save sheet opens Saved to choose its eligible child collections.

Implementation and focused validation are complete. The feature is ready to commit.

Context and orientation

Likes is a profile-owned persisted Codex (post collection). Followed and Saved Searches are virtual Codices: live feeds produced from local creator memberships and named queries. Their storage and mutation policies remain intact. app/src/main/java/com/theoriacodex/app/codex/CodexListScreen.kt renders Library tiles; SaveToCodexSheet.kt renders save targets. app/src/main/java/com/theoriacodex/app/ui/TheoriaApp.kt owns navigation. Route boundaries provide each collection's posts and live owners.

The Saved overview uses the child collection's retained FAB state (filters and sort), including selected saved queries. Ordinary post cards retain existing simultaneous visible autoplay. No production channels, devices or databases are touched.

Phases and work plan

  1. Add a presentation-only Saved identity and shared category/count helpers. Replace three Library tiles with Saved while retaining ordinary collection order and restored grid ownership.
  2. Add ui/routes/SavedCodexRoute.kt with three horizontal post rows using existing destination boundaries, retained filters, duration owner and shared media cards. Headers open existing Codex routes; cards open Viewer with the visible section list. Loading, empty and failed states remain visible with retry.
  3. Group Likes beneath Saved in the existing save sheet, retaining profile selection, exclusions, search and back navigation. Show read-only virtual categories without allowing invalid membership writes.
  4. Add focused behavior tests, run a single validation batch, update evidence and commit only this feature.

Living log

Progress

2026-10-16: completed Library grouping at the original Likes position, three carousel rows, shared saved filters, Viewer launch, nested picker navigation, profile exclusions and read-only automatic-feed rows. Added focused UI coverage and updated AGENTS.md.

Discoveries

Saved Searches stores queries, not post snapshots; its saved view means the existing retained query selection, filters and sort. Followed and Saved Searches cannot accept arbitrary posts. The first UI run found unsupported PostId lazy-row keys; canonical source-qualified strings fix saveable navigation restoration. Added child rows exposed a height allocation issue in the save sheet; a weighted bounded list keeps the profile and create controls reachable. Static analysis prompted extraction of tile and picker presentation helpers.

Decisions

2026-10-16 / Codex: use presentation grouping without a database migration or general nested-collection architecture. Keep all three existing destinations and mutation rules.
