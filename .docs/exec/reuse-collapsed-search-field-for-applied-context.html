Purpose / Big Picture

After a search is applied, the empty unfocused field shows one line such as Pixiv · klee · 2 filters. Tapping it restores the normal text-entry surface immediately. Long context ellipsizes inside the current field.

Context And Orientation

SearchQueryUiState.applied and appliedSourceScope are authoritative for displayed results. SearchScreen owns focus plus visibility filters such as animated-only, duration, hide-liked, and hide-saved. The current OutlinedTextField already has an unfocused placeholder slot, so applied context can occupy that slot without mutating the real input value.

The summary must never read draft query/source values. Draft changes continue to use existing chips and pending-state feedback until Apply succeeds.

Phases And Work Plan

  1. Add a pure formatter that prioritizes applied source, first useful query term, then a compact filter count.
  2. Render the summary only when the field is unfocused, input is blank, and Search has applied/executed context.
  3. Use one line with ellipsis; retain the generic entry hint before the first search.
  4. Add formatter and source-ownership regression tests, then run one bounded app validation batch.

Surprises And Discoveries

The field's real value is only transient autocomplete input; applied terms already live separately. A presentation-only placeholder avoids cursor, keyboard, and draft synchronization risks. Temporary source scopes are already canonical and name-sorted, so their compact label can deterministically retain the first source plus a count.

Decision Log

Decision: derive the summary from applied state and render it as placeholder content. Rationale: it preserves authoritative data ownership and restores normal editing automatically on focus. Date/Author: 2026-08-08 / Codex.

Outcomes And Retrospective

UX-005 is implemented, deterministically validated, and user-accepted. The existing field shows applied source, first useful term, and active-filter count when unfocused; focus restores normal entry, and overflow ellipsizes without adding height. Four focused tests, compilation, and Detekt passed.

Idempotence And Recovery

No migration or device action is required. Tests and static checks are safe to rerun. If interrupted, keep the input value untouched and derive presentation only from existing state.
