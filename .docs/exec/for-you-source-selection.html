Purpose / Big Picture

The For You header will show Unified or the current source with a dropdown arrow. Choosing a source regenerates the feed using only that source's liked or trending tags, queries only that adapter, and keeps pagination inside that source. Choosing Unified restores the existing multi-source behavior.

Context And Orientation

ForYouScreen.kt renders the feed and currently shows the active recommendation profile name under the title. ForYouCoordinator.kt selects per-source tag seeds, calls the unified orchestrator, and owns pagination. TheoriaApp.kt connects the active profile and callbacks. A source means one provider adapter, while Unified means all currently enabled and available adapters.

The feed must be constrained before tag generation and provider execution. Filtering the visible list afterward would leak unrelated tags, waste requests, and allow pagination to repopulate unwanted sources.

Phases

1. Coordinator contract

Add an in-memory selection defaulting to Unified, expose enabled source options, and refresh through a source-restricted effective source set. Acceptance: seed summaries, results, statuses, and pagination all contain only the selected source.

2. Header interaction

Replace the profile subtitle with a dropdown label and arrow. Acceptance: the current choice is visible, available enabled sources are selectable, and selection triggers a feed refresh.

3. Verification

Add focused regression tests, run app tests and compile/assemble checks, then record evidence and any remaining manual device acceptance.

Surprises And Discoveries

  • The existing coordinator already carries independent per-source query overrides and page tokens, so restricting the source set at its entrance preserves the rest of the feed pipeline.
  • adb devices returned no connected devices, so user-visible interaction acceptance remains explicitly pending rather than inferred from compilation.

Decision Log

  • Decision: keep source selection session-scoped. Rationale: the request defines feed interaction, not a new persisted setting; Unified remains the safe startup default. Date/Author: 2026-07-10 / Codex.
  • Decision: keep recommendation profiles active behind the feed but remove the profile name from this header. Rationale: likes and blacklists remain profile-scoped while the requested surface becomes source-scoped. Date/Author: 2026-07-10 / Codex.

Outcomes And Retrospective

The profile subtitle is now a source selector. The coordinator defaults to Unified, rebuilds the feed when the source changes, and uses the selected source as the common boundary for affinity data, seed tags, initial results, shuffle, and later pages. Focused tests prove Unified → Pixiv → paginated Pixiv → Unified behavior. All automated validation passed; only physical/emulated device interaction remains.

Idempotence And Recovery

All Gradle and HTML checks are safe to rerun. No data migration or destructive operation was introduced. If follow-up work is needed, inspect this plan and git diff; source selection is session-scoped and resets safely to Unified after app restart.
