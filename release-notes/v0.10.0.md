# Theoria Codex v0.10.0

## Highlights

- Build more precise searches and Automatic Codex rules using required tag groups with flexible alternatives.
- Manage Codex collections more efficiently with direct collection-to-collection saving, compact bulk actions, and remembered feed controls.

## New

- Create searches such as `landscape AND (night OR sunset)` by adding OR alternatives to any required tag group.
- Build source-specific Automatic rules where every group is required while tags inside each group act as alternatives.
- Add an individual post or multiple selected posts from one Codex directly into another.

## Improvements

- Grouped searches preserve their structure when applied, paginated, restored, and reopened from Recents without changing the selected result order.
- Search, For You, creator profiles, and individual Codices retain their own applicable filter and sorting controls across relaunches.
- Automatic rule editing now presents one source at a time and provides tag filtering for large collections.
- Codex edit mode uses compact bulk actions and displays the current selection count.
- The Codex currently being viewed is excluded from available add destinations.

## Fixes

- Fixed later Automatic rule groups becoming incorrectly numbered after the final tag in an earlier group was removed.
