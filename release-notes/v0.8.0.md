# Theoria Codex v0.8.0

## Highlights

- A more polished browsing experience with clearer navigation, durable history, faster media previews, and safer reversible actions.
- Expanded Codex and For You controls make it easier to manage saved posts and recommendations without leaving the current screen.

## New

- Manage Codex collections from their tile menu, including search, rename, sharing, export, and deletion.
- Select and remove multiple posts while editing a Codex.
- Undo cleared Recents, removed Codex posts, and newly hidden For You recommendations.
- Long-press posts in For You and Recents to open the shared post action menu.
- See the active source, query, and filters directly in the collapsed Search field.
- Clear a recommendation profile's liked posts directly from its Likes Codex.

## Improvements

- Settings now opens with compact, collapsed sections and useful summaries, while remembering each section's expanded state.
- Recommendation profile creation and management use a cleaner, more compact Settings layout.
- Search, For You, and Creator Profile now share consistent filter controls.
- Codex, Creator Profile, and Recents use the same media-focused masonry presentation as Search.
- Recents now stores activity more reliably and keeps Watched and Codex history independent.
- Top-level navigation switches directly between tabs and remains correctly sized with Android three-button navigation.
- Video and animated previews reuse media infrastructure more efficiently while preserving simultaneous visible autoplay.

## Fixes

- Fixed Search scroll position jumping after closing a post.
- Fixed recommendations being regenerated unnecessarily when reopening For You.
- Fixed Pixiv native sign-in callbacks that legitimately omit OAuth state.
- Fixed animated media durations failing to retry after temporary errors.
- Fixed Recents losing Codex launch context and richer saved post details.
- Restored long-press actions and consistent grid spacing in Recents.
- Removed raw post IDs from user-facing titles and action surfaces.
- Improved Pixiv artwork framing and feed-card control alignment.
- Improved the touch targets and accessibility state of compact controls.
