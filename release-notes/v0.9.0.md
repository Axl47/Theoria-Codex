# Theoria Codex v0.9.0

## Highlights

- Codex collections can now organize themselves using Automatic tag rules when matching posts are liked.
- Browsing and viewing media is faster and more resilient, with reusable previews, adjacent-media prefetching, persistent duration information, and reliable Retry across every media type.
- Private on-device statistics reveal how you browse, watch, search, share, and build your Codices without sending analytics elsewhere.

## New

- Create source-aware Automatic rules from a Codex’s existing tags to route newly liked matching posts into that collection.
- Review private lifetime and current-library statistics from the new Stats section in Settings.
- Reopen saved Multi-Search and For You recommendation searches from Recents with their original sources and tags.
- See the farthest media item reached in multi-media posts directly in Recents → Watched, shown as progress such as `50/742`.
- Filter Search results with Hide Watched.
- See animated-media durations directly on feed cards.

## Improvements

- Filter Codex collections by media type, duration, source, language, and full-color status, with sorting available from the same filter sheet.
- Open Viewer using the exact filtered and sorted Codex collection currently shown.
- Feed cards use cleaner preview overlays for source and Recents context while reserving footers for meaningful titles.
- Feed previews remain reusable across scrolling and navigation, reducing playback churn while preserving simultaneous visible autoplay.
- Viewer opens already-known media without waiting for an unnecessary provider refresh and prefetches nearby media through the shared playback cache.
- Animated-duration discovery now runs progressively during browsing, persists bounded results, and avoids slowing active scrolling.
- Pixiv Ugoira and Hitomi gallery loading reuse work more efficiently and operate within bounded resource limits.

## Fixes

- Fixed saved For You searches being lost or cancelled when replayed after a cold start.
- Fixed Retry failing to restart some images, videos, GIFs, animated WebP files, and Pixiv Ugoira.
- Fixed static or unresolved posts appearing in active animated-duration ranges.
- Improved GIF fallback behavior and Hitomi duration discovery.
- Fixed Viewer sessions being lost during rapid post re-entry.
- Fixed Codex covers remaining broken when their preferred image fails.
- Kept Viewer controls visible longer and prevented Undo or Retry messages from remaining indefinitely.
- Hidden source-weight controls for disabled sources and refined several compact action layouts.
