# Theoria Codex v0.7.0

## Highlights

- Search is more flexible with temporary multi-source searches.
- Settings are easier to navigate and remember your preferred layout.

## New

- Combine two or more source chips for a temporary search scope without changing saved source settings.
- Collapse individual Settings sections and preserve their expanded or collapsed state across launches.

## Improvements

- Search paging now preserves your position instead of jumping back to the top.
- Excluded sources no longer clutter actionable search status messages.
- Search results remain stable as additional pages load.

## Fixes

- Prevented malformed provider records from making Unified search stop paging too early.
- Removed duplicate canonical results from Hitomi searches.
