# Theoria Codex v1.5.0

## Highlights

- Share your Codex stats with friends and compare them side by side, including top posts you can open in the Viewer.
- A new Diagnostics report in Settings makes it easy to send crash and error details, with personal details removed.
- Sites with an API key work more reliably, and refusals lead you straight to the fix.

## New

- Share or download your Codex stats as a file from any of your profiles. You can leave out any profile, Codex or post first, and the totals are recalculated to match.
- Compare your stats with a file a friend sent you. Overall time in the app, app opens, posts watched and saved, and searches appear side by side, and top posts show thumbnails.
- Settings > Diagnostics shares or downloads recent crashes and errors as a file, with web addresses and account details removed.
- Tap a post in a Codex's Top posts list in Stats to open it in the Viewer.
- When a site refuses your account in search, a re-test or a shared link, a button takes you straight to that site's API key field.
- A site that needs a browser check shows its API key fields before you add it.
- Images and videos that a Danbooru-type site refuses are retried once with your API key, on that site's own addresses only.

## Improvements

- When a link leads you to set up a site, the post opens once the site is added.
- The message for rejected API keys now mentions keys limited by IP address or permissions.

## Fixes

- The update prompt shows the new version, its download size and its release date instead of "unknown".
- A site's API key is tried first when you add, re-test or browser-check it, so a valid key works even where visitors without an account are refused.
- A wrong API key is reported when you enter it instead of being saved untested.
- Saving a new API key lets the site's requests through right away instead of waiting out a "site is down" mark.
- Adding a site back after removing it no longer leaves it marked as down for up to 10 minutes.
- The check that runs at launch no longer marks a site with a saved key as needing verification.
- A shared post whose files a site withholds from your account now says so instead of "post was not found".
- Error text points to Settings > Sites instead of an Accounts page that no longer exists.
