# Theoria Codex v1.2.0

## Highlights

- The search editor is rebuilt to show your tags as one readable query that you edit in place.
- Build a search directly from a post's info or a Codex, and see it take shape as you tap tags.
- Sort your Codex Library by what you actually watch and open.
- The Viewer's header and footer now stay hidden until you tap.

## New

- Post info shows your search under the tags and can run it from there, without going to Search first.
- Add a post's tag to an "or" group from post info with "+ or". Tags of another type dim while a group is the target.
- A Codex's "Search with these tags" can exclude tags, build "or" groups and filter the Codex's tags. You can also switch source in place, without an extra menu.
- Sort the Codex Library, and the library order in Add to Codex, by Most watched or Most opened, using the time and open counts shown in Stats.
- Removing a tag from the search editor offers a brief Undo.

## Improvements

- Search editor: tags read as one query in the order you added them, with "or" groups inline and excluded tags below.
- Search editor: add an alternative right on its "or" group. The mode and target rows are gone, and the button beside the field shows how the next tag joins.
- Search editor: tapping a tag opens its actions next to it, the field sits just above the keyboard, and your query stays visible above the suggestions while you type.
- Search editor: Search is now at the top, with Favorites, Undo last search and Reset in its overflow menu.
- Post info: tags wrap with their full names instead of being cut off in columns. Tap a tag to add it, again to exclude it, and once more to clear it.
- Post info: artists, series and characters come before general tags, very long tag groups collapse behind "+N more", and counts are shortened, such as 84k or 1.2m.
- Post info: a compact action row lets tags start near the top. Go to Search and Open in browser are under More.
- Codex search: Randomize is now Draw, which takes up to five tags from one saved post so they are known to appear together.
- Codex search: each tag keeps its type, so an artist is searched as an artist.
- Recents: sections (All, Watched, Codex, Searches) moved from a row of chips into a dropdown beside the source selector, leaving more of the screen for your history.

## Fixes

- Moving to another post or image in the Viewer, or zooming by pinching or double-tapping, no longer brings back the header and footer.
- The search bar over results now reads "mountain or snow" for an "or" group instead of listing the tags as if both were required.
- When an "or" group's tag type rules out suggestions, the editor says so instead of showing nothing.
- Adding a typed tag from another source's post now warns you before it switches Search to that source and removes your other typed tags.
