# Theoria Codex v1.9.2

## Highlights

- When a saved file goes bad, the original is always kept and never overwritten.
- The app shows "Saved data could not be opened safely." with Retry instead of closing when saved data can't be opened.

## Improvements

- Settings → Recovered storage now also lists Settings, Statistics, custom sites and the last-screen state when one of them had to start over.
- Storage lists a collection whose offline copies can no longer be opened, with 0 posts available. Removing it deletes those copies; before, only Clear did.

## Fixes

- Post counts next to a saved nhentai gallery's tags no longer disappear after the gallery is opened through nhentai's backup copy, or after importing a shared collection that contains it.
- If Settings, Statistics, custom sites or the last-screen state became unreadable a second time, the copy kept from the first time was replaced. Each unreadable file is now kept separately.
- An unreadable file that could not be set aside was overwritten anyway. It is now left untouched until it can be set aside.
- After going back to an older version, data saved by the newer version could close the app at launch. That data is now left untouched.
